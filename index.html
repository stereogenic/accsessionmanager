🚀 Quick Start Guide

1. Installation

  • Avoid Windows OS system folders (e.g., Documents or OneDrive sync paths).
  • Unpack and place the ACC-SessionManager folder into your desired directory
    (e.g., C:\Apps\ACC-SessionManager or D:\ACC-SessionManager).

2. Setup & Configuration

  • 1. Launch ACC-SessionManager
  • 2. Configure the server using the global server settings.
  • 3. You can close the gui when ACC Session Manager is Running.
  • - Access the gui via the System Tray or Start the App.
  • - Its recommended to add the gui to your browser bookmarks.

3. Network Access

  • 1. Setup the udp and tcp game ports in the gui or leave the game default.
  • 2. Start the Server in the gui and allow accServer.exe both Private and Public.
  • 3. Configure your network router to allow the incoming game ports or...
  • 4. You can enable uPnp in the Global Server Settings.

🚦 Server Control Interface

Start and stop the server in either Rotation Mode or Normal Operation Mode. The green status indicator confirms active server execution.

⚙️ Global Server Settings

Expand accordion panels to configure network ports, server passwords, driver safety requirements, and session rules.

⚖️ Global Balance of Performance (BoP)

Import existing bop.json files or build custom ballast and restrictor presets per car and track combination.

🏎️ Global Entry List Manager

Import, modify, and assign driver Steam IDs, car choices, ballast, and restrictors visually.

🛡️ Global Ban Management

  • Enable or Disable the Global Ban List.
  • Add Player Name and Steam ID to apply a Permanent Ban.
  • Browse the lastest Result files to find Player Names.

    • How To Ban a Player
  • Use the /ban Admin Command ingame to Ban the Player from the session.
  • View the Latest Session Results & Add the Player to Banlist.
  • Or Manually Add the Player Name and Steam ID.
  • When the Server Restarts The Player will be Banned.

💾 Backup & Restoration

Export your full configuration, rotation lists, BoP settings, and ban lists into a single JSON backup bundle for safe keeping or server migration.

📅 Track Rotation & Session Fine-Tuning

Re-order track queues on the fly, Adjust Race Rules, Weather Variance and more.
